# Mossbud Releases

Distribution binaries for [Mossbud](https://github.com/samuelbanapour/mossbud) (private repo — this one exists only to host public downloads for sideloading).

- **iOS**: add `https://github.com/samuelbanapour/mossbud-releases/releases/download/v1.0.0/source.json` as a source in AltStore.
- **Android**: download `Mossbud.apk` directly from the [latest release](https://github.com/samuelbanapour/mossbud-releases/releases/latest) and install via Settings → Install unknown apps.
